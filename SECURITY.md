# Security reports

Please report exploitable bugs privately. Use **Report a vulnerability** in this repository's GitHub Security tab when that option is available. If it is unavailable, open a public issue asking for a private contact channel without including exploit details, private files, or credentials.

Include the affected Frameyard version, operating system, steps to reproduce, and the likely impact. A small test project helps, but remove personal media and secrets first.

Security fixes target the current release. Older releases may not receive backports. Project JSX and project-local build configuration can execute code on your machine, so open only projects you trust.
