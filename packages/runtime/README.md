# @diffusionstudio/runtime

Frameyard's headless editor runtime uses [koota](https://github.com/pmndrs/koota)
for the composition world, traits, actions, media decoding, and capture.

The editor, capture, and export paths share this package. The browser UI lives
in `apps/web`; Solid bindings live in `@diffusionstudio/koota-solid`. For
composition authoring, start with the
[JSX reference](../../docs/reference/jsx/README.md).
